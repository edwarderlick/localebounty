## Brand & Style
This design system pairs the graphic rigor of Swiss editorial typography with high-contrast neo-brutalist tech cues. Tailored for a decentralized translation bounty network powered by autonomous consensus validators, the aesthetic communicates cryptographic integrity alongside human linguistic nuance.

The visual language balances three foundational pillars:
- **Architectural Structure:** Strict grid-bound layouts, high-contrast block sections, and stepped mosaic pixel cutouts evoke digital precision, modular smart contracts, and decentralized data validation.
- **Editorial Punch:** Deep forest-green structural foundations contrast against warm ecru canvases and electric orange signals, creating a tactile, print-inspired digital experience.
- **Micro-Editorial Accents:** Skewed contrast badges, floating micro-stickers, and pastel taxonomy pills inject wit and visual dynamism, distinguishing human translators, validation rounds, and bounty tiers without sacrificing professional enterprise authority.

## Colors
The color palette relies on high-contrast, deliberate color blocking rather than subtle tints. Deep forest greens provide an authoritative base, while signal orange drives critical user interactions and validation alerts.

### Palette Architecture
- **Primary Canvas & Depth:**
  - `Deep Forest Base` (`#0F2D1E`): Used for dominant structural cards, navigation bars, and terminal-grade containers.
  - `Forest Pine Surface` (`#163826`): Secondary dark container fill for active states, card hover tiers, and nested validator panels.
  - `Warm Ecru` (`#F9F5EB`): The default global page canvas, evoking archival paper and high-grade print editorial surfaces.
  - `Muted Sand` (`#F4EFE6`): Sub-surface fill for nested cards, secondary modules, and table headers.

- **Action & Kinetic Signals:**
  - `Signal Tangerine` (`#FF5500`): Primary call-to-action color, bounty reward tags, and irreversible transaction triggers.
  - `Flame Orange` (`#F05315`): Active hover state and urgent deadline indicators.

- **Pastel Category Accents (Taxonomy & Status Pills):**
  - `Validator Lime` (`#D4F46B`): Consensus approved, active validator rounds, high-payout tier tags.
  - `Bounty Pink` (`#FFB4D6`): High priority tags, editorial critique badges, community notes.
  - `Consensus Cyan` (`#7CE3EB`): Open language pools, cryptographic proofs, protocol status.
  - `Warning Yellow` (`#FFE066`): Under review, staking lockup warnings, dispute periods.

## Typography
Typographic rhythm relies on the tension between the geometric, structural personality of `Space Grotesk` and the neutral, high-legibility clarity of `Plus Jakarta Sans`.

- **Display & Headlines:** Set exclusively in `Space Grotesk` with tight optical tracking (`-0.03em` to `-0.04em`) and compact line heights to create solid headline lockups.
- **Accompanying Body Copy:** Set in `Plus Jakarta Sans` to guarantee effortless scanning across multi-paragraph translation strings, source diffs, and validator deliberation notes.
- **Sticker & Meta Typography:** Micro-stickers, language pair pills, and staking status labels use uppercase or title-case `Space Grotesk` with amplified tracking (`+0.04em` to `+0.06em`) for immediate visual hierarchy.

## Layout & Spacing
The layout uses an architectural 12-column grid system bounded by solid margins, delivering an authoritative, structural canvas.

### Layout Rules
- **Grid Architecture:** 12-column desktop grid with fixed 1.5rem gutters; collapses to an 8-column layout on tablet devices and a 4-column layout on mobile devices with 1rem gutters.
- **Stepped Pixel & Mosaic Framing:** Visual containers use stepped cutout grids (48px square modular units) placed at corner intersections or container edges to frame photography, proof logs, and validator signatures.
- **Split-Screen Sections:** High-contrast color blocks sit edge-to-edge (e.g., solid `#FF5500` abutting deep `#0F2D1E`), creating crisp, planar spatial divisions with zero gap between parent sections.

## Elevation & Depth
This design system avoids soft, floating blur-based drop shadows in favor of flat planar stratification and high-contrast structural borders.

- **Planar Tonal Stacking:** Visual depth is achieved through stark field contrast. Pure `#F9F5EB` panels lie over `#0F2D1E` structural canvases; pastel cards sit directly on top of saturated `#FF5500` banner zones.
- **Ghost Rules & Structural Borders:** Interfaces rely on 1px solid borders using either `rgba(15, 45, 30, 0.12)` on cream surfaces or `rgba(249, 245, 235, 0.15)` on forest backgrounds.
- **Hard Offset Sticker Shadows:** Interactive micro-stickers and floating status pills use a solid, zero-blur 2px offset drop shadow (`box-shadow: 2px 2px 0px #0F2D1E`), reinforcing an physical, screenprinted aesthetic.

## Shapes
Sharp, architectural, and brutalist. All cards, primary action triggers, input containers, and structural sections adhere to a strict `0px` radius (`roundedness: 0`). 

The only deliberate exceptions are:
- **Micro-Sticker Category Tags:** Skewed micro-pills applied with `transform: rotate(-2deg)` to `rotate(3deg)` featuring full-capsule rounded ends (`9999px`) to create an authentic tactile badge effect against rigid rectangular blocks.
- **Stepped Pixel Chamfers:** Modular rectangular notches (e.g., 16px to 32px stepped indents) cut into media corners, echoing mosaic data verification.

## Components

### Buttons
- **Primary Action (Signal Orange / Forest Invert):** Sharp rectangular containers with `Space Grotesk` font, bold weight, accompanied by a trailing arrow (`→`). Background in `#FF5500` with `#FFFFFF` text, or `#0F2D1E` with `#F9F5EB` text. Hover state shifts background color with zero radius transition.
- **Ghost & Accordion Triggers:** Clean 1px stroke borders, transparent surfaces, full-width interaction rows with top-right arrow indicators (`↗`) that invert color upon hover.

### Floating Micro-Stickers & Category Pills
- **Tilted Micro-Pills:** Small capsule chips floating over headline bounds or card shoulders with a `-2deg` or `+3deg` CSS rotation. Solid backgrounds in `#D4F46B`, `#FFB4D6`, `#FFE066`, or `#FF5500` with `#0F2D1E` bold label text and a crisp `2px 2px 0px #0F2D1E` shadow.
- **Language / Validator Badges:** Sharp rectangular micro-tags displaying language pairs (e.g., `EN-US → JA-JP`) and consensus validator quorum counts.

### Cards & Grid Containers
- **Vibrant Pastel Feature Cards:** Full flat fills in pastel cyan, lime, yellow, and blush pink with sharp `0px` corners, indexed numbers (e.g., `01`, `02`), mono glyph icons at top-left, and heavy title typography anchored to bottom-left.
- **Stepped Pixel Mosaic Cards:** Media and data cards bordered with interlocking block step-outs that mimic modular data blocks and validator nodes.

### Input Fields & Search Bars
- **Terminal Inputs:** Set within deep forest `#0F2D1E` or ecru `#F9F5EB` backgrounds. Enclosed by 1px crisp borders, containing inline submit button lockups directly within the input border framework.

### Checkboxes, Radio & Validator Toggles
- **Sharp Brutalist Checkboxes:** `18px × 18px` squares with a 1.5px solid `#0F2D1E` border, no rounding. Checked state fills completely with `#FF5500` or `#0F2D1E` with an inner white geometric checkmark.

### Additional Platform-Specific Components
- **Consensus Quorum Meter:** Segmented flat bar showing GenLayer validator votes in `#D4F46B` (Validated), `#FFE066` (Deliberating), and `#FF5500` (Challenged).
- **Bounty Lockup Ticket:** Editorial receipt-style modular panel displaying staked tokens, translation word count, and real-time smart contract lockup countdowns.
