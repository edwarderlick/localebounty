# Design sources

Original Stitch HTML and screenshots for the six product screens plus the brand mark, and the editorial token sheet. These files are not imported by the Vite app. The React implementation lives in `src/`.

Each screen folder keeps `code.html` and `screen.png` together.

| Folder | Screen |
| --- | --- |
| `localebounty_task_board/` | Task Board |
| `localebounty_create_task/` | Create Task |
| `localebounty_task_detail/` | Task Detail |
| `localebounty_submit_translation/` | Submit Translation |
| `localebounty_validation_decision/` | Validation & Decision |
| `localebounty_string_library/` | String Library |
| `localebounty_brand_logo/` | Brand mark |
| `decentralized_precision_editorial_impact/` | `DESIGN.md` color and type tokens |

The in-app demo at `/demo` is the React port of these screens on `demoStore`, not these HTML files.
